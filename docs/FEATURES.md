# 기능 범위와 다음 단계

v1.2까지 확인한 방향과 후속 검토 과제를 정리한다. 기능 방향이 합의되어도 물리설계·구현 완료를 뜻하지 않는다.

| 기능 | 회원 | 비회원 | 상태 |
| --- | --- | --- | --- |
| 법규·판례 기반 질의응답 | 지원 방향 | 지원 방향 | 원문과 설명을 구분하는 Verbatim RAG |
| 대화 보관 | 보유기간 별도 검토 | 1개월 방향 | 기산점·만료 처리 미확정 |
| 사건관리·사실관계 | 사용자 확인 후 저장 | 지원하지 않음 | v1.2 사용자 검토 반영 |
| 첨부문서 질의 | 회원 전용 | 지원하지 않음 | HWP/HWPX 초기 지원 목표, 상세 제한 미확정 |
| 관심 법규·판례와 사이트 내 알림 | 검토 대상 | 대상 아님 | v1.2 스키마 초안, 최종 미승인 |
| 법률용어 쉬운 설명 | 설계 검토 | 공개 범위 검토 | 사전 구조·출처·검수 정책 미확정 |
| 삭제 | 소프트 삭제 | 소프트 삭제 | 업무 DELETE 금지, 별도 개인정보 파기 설계 필요 |

## 검토 순서

1. 공통코드 계층·식별 범위·무결성 및 법규 관계의 버전·시점 관리를 정한다.
2. 용어사전과 회원 인증, 사건 확인, 첨부 처리, 알림 상세 정책을 검토한다.
3. 전체 FK·인덱스·소유권·소프트 삭제 전파·복구·개인정보 파기 절차를 확정한다.
4. 전체 물리설계 최종 승인 후에만 DB·Prisma·마이그레이션·코드 적용을 진행한다.

현재 승인된 실행 범위는 한국어 설계 문서 작성·커밋·푸시다. 다음 단계의 상세설계나 구현을 이 문서로 자동 승인하지 않는다.
