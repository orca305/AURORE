# 대화 안에서 법률용어 찾기

2026-11-19. 대화 입력창의 **용어 찾기**로 현재 대화를 유지하면서 용어사전을 조회한다. 메시지에서 100자 이내 용어를 선택한 뒤 버튼을 누르면 검색어에 채워진다. 직접 입력해 검색할 수도 있다. 선택만으로 자동 검색하거나 대화 전체를 사전에 전송하지 않는다.

- 검색 패널은 입력창 아래에서 접고 펼친다. 첨부파일 패널과 번갈아 열 수 있다. 대화 작성 내용과 전송 중인 답변 작업을 변경하지 않는다.
- 공개·미삭제 용어만 표시한다. 같은 이름은 출처별로 확인한다. 정의 미리보기·출처를 표시하고 상세 풀이/원문은 새 탭으로 연다.
- 10/20/50개 조회, 이전/다음 페이지, 초기화, 검색 결과 새로고침을 지원한다. 패널 새로고침은 대화 페이지 전체를 다시 로드하지 않는다.
- 검색 중복/닫기/초기화 때 이전 요청을 취소하고 늦은 응답이 새 상태를 덮어쓰지 않도록 한다. Escape로 닫으면 버튼으로 초점을 되돌린다.
- /api/terms/lookup은 서버의 기존 공개 /terms 조회만 호출한다. 관리자 조회 옵션과 인증 쿠키·토큰을 전달하지 않으며 응답은 필요한 공개 필드만 반환한다. 비공개/삭제 항목이나 인증정보가 담긴 출처 링크는 거부한다. 검색 입력은 최대 100자, 결과/페이지/출처 형태를 확인하며 캐시는 사용하지 않는다.
- 데이터는 기존 DB를 조회한다. AI 생성·OCR·학습·용어 데이터 자동 등록을 수행하지 않는다. 집 데스크탑 자료에는 손대지 않았다.

검증: 실제 Next 서버와 임시 응답 서버로 도구 버튼 서버 렌더링, 조회 개수와 페이지 중복 방지, 비공개/삭제/잘못된 출처 거부, 빈 목록, 잘못된 응답/연결 오류, 쿠키·인증정보 미전달을 확인했다. 모델과 실제 DB는 사용하지 않았다. 프런트 빌드·정적 검사도 통과했다. 실제 대화 상호작용과 화면 위치·색상, 데스크탑의 실제 용어 목록 조회는 연결 후 사용자 확인이 남아 있다.

실행할 검사는 frontend에서 node --test tools/term-lookup.test.mjs다. 프런트 빌드 후 실행하며 임시 서버는 자동으로 닫는다.
