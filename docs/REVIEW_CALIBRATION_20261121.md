# 근거 선별(검토) 보정과 모델 프로필 — 2026-11-21

## 문제
검색은 정답 조문을 후보 12개 안에 잘 올렸지만, 그 뒤 선별(로컬 모델의 추출·검토)에서 정답을 놓치거나 엉뚱한 조문을 승인했다.
통과를 늘리면 오인용도 느는 맞교환이 있었다.

## 한 일
1. **법령 전용 프롬프트** (`source: "law"`): 일상어와 법률용어를 의미로 맞추도록 지시. 첨부자료 검토는 기존 엄격한 기준 유지. 끄기: `AURORE_LAW_PROMPT=0`.
2. **등급 방식** (기본): 후보 3개를 한 번에 direct/related/none 으로 분류(`/documents/grade`) → direct 중 검색 순위가 높은 후보를 하나씩 엄격 재확인(`source: "verify"`, 최대 2개) → 통과한 첫 후보를 인용. 모델 호출이 줄어 더 빠르다. 예전 방식으로: `AURORE_REVIEW_MODE=classic`.
3. 진단 도구 `backend/tools/diagnose-review.mjs` (검토 서버를 `AURORE_REVIEW_DEBUG=1` 로 띄우면 묶음별 추출·승인 건수를 본다).

## 2차 개선 (같은 날 오후): 검색 후보·선별 방식·해설·오인용

실패 6건을 열어 본 결과 원인은 서로 달랐다. 질문 분석이 법령을 못 짚어 후보에 정답 법령이 없는 경우(반려견, 학원 폐업),
선별이 같은 법령의 다른 조문이나 다른 법령을 고른 경우, 평가가 법령 하나만 정답으로 보는 경우(퇴직금 지급 시기: 근로기준법 제36조도 맞음).

1. **법령 찾기**: 법령별 조문 임베딩 평균(중심 벡터)으로 질문과 뜻이 가까운 법령을 찾는다(`law-titles.ts`, 인덱스 `D:/DATA/embeddings/law-titles`,
   만들기 `backend/tools/embed-law-titles.mjs`). 이름만 임베딩하면 1위 43%, 중심 벡터는 1위 70%·5위 안 93%(122문항). 2위 법령은 1위와 점수 차 0.01 미만일 때만 쓴다.
2. **법령별 후보 보장**: 짚은 법령마다 질문과 가까운 조문을 최소 2개 검토 대상에 넣는다(`ensureLawSlots`). 끄기 `AURORE_LAW_SLOTS=0`, 법령 찾기만 `AURORE_LAW_TITLES=0`.
3. **선택 방식** `AURORE_REVIEW_MODE=choose`: 후보 12개를 한 번에 보고 하나 고르기(`/documents/choose`). 오인용이 줄지만 통과가 같거나 낮아 **기본은 등급 방식 유지**.
4. **해설 재시도**: 검증 거절 시 사유(고정 문구)를 알려 주고 한 번 더 시도, 요약만 문제면 검토를 통과한 첫 규칙 항목으로 요약을 대신한다. 끄기 `AURORE_EXPLAIN_ATTEMPTS=1`.
5. **인용 법령 일치 검사**: 인용 법령이 분석이 짚은 법령·법령 찾기가 고른 법령(시행령·시행규칙 포함)에 없으면 확정하지 않는다. 끄기 `AURORE_LAW_GATE=0`.
6. 외부 모델: Sonnet·Opus 는 `thinking: disabled` 를 거부(400)해서 Haiku 에만 보내도록 수정(`external_model.py`).
