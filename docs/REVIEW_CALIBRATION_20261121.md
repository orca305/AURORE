# 근거 선별(검토) 보정과 모델 프로필 — 2026-11-21

## 문제
검색은 정답 조문을 후보 12개 안에 잘 올렸지만, 그 뒤 선별(로컬 모델의 추출·검토)에서 정답을 놓치거나 엉뚱한 조문을 승인했다.
통과를 늘리면 오인용도 느는 맞교환이 있었다.

## 한 일
1. **법령 전용 프롬프트** (`source: "law"`): 일상어와 법률용어를 의미로 맞추도록 지시. 첨부자료 검토는 기존 엄격한 기준 유지. 끄기: `AURORE_LAW_PROMPT=0`.
2. **등급 방식** (기본): 후보 3개를 한 번에 direct/related/none 으로 분류(`/documents/grade`) → direct 중 검색 순위가 높은 후보를 하나씩 엄격 재확인(`source: "verify"`, 최대 2개) → 통과한 첫 후보를 인용. 모델 호출이 줄어 더 빠르다. 예전 방식으로: `AURORE_REVIEW_MODE=classic`.
3. 진단 도구 `backend/tools/diagnose-review.mjs` (검토 서버를 `AURORE_REVIEW_DEBUG=1` 로 띄우면 묶음별 추출·승인 건수를 본다).
