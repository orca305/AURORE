# 기존 기능·공통 기반 현행화 상태

기준일: 2026-11-06. v3.2 문서 커밋 `fd544ae` 이후 사용자가 코드 현행화를 요청하고, 범위를 **기존 기능과 공통 기반**으로 선택했다. 이전의 구현 보류는 이 범위에서 해제되었다. [v3.2 요약](V3_2_SUMMARY.md)은 당시의 결정 기록으로 보존한다.

## 반영 범위

- 기존 법규 목록·등록을 `Legal` / `legal`로 전환하고 `/legals`를 기본 주소로 제공한다. `/laws`는 기존 필드명을 변환하는 호환 주소로 유지한다.
- 법규 검색·페이지 제한(기본 20, 최대 100), 입력 검증, 중복 등록 409 응답, BIGINT 식별자의 문자열 직렬화를 적용했다. 호환 API도 식별자는 문자열이며 조회는 제한된 페이지 단위다.
- 공개 목록에서 삭제 법규를 제외한다. 법규 버전·조문 조회는 삭제된 법규·버전·조상 조문도 제외한다. 업무 삭제 API나 물리 삭제 기능은 추가하지 않았다.
- 법규 등록은 수집 전용 Bearer 자격증명이 필요하다. `LEGAL_INGEST_TOKEN`을 32바이트 이상으로 설정하지 않으면 등록은 닫힌다. 회원·관리자 인증을 구현한 것은 아니며, 수집 토큰은 브라우저에 전달하지 않는다. 운영 환경에서는 HTTPS와 별도의 접근·요청 제한을 적용해야 한다.
- Prisma에 `legal`, `legal_ver`, `legal_provi`, `src_snapshot`, `cmmn_cd`, `cmmn_cd_hist` 총 6개 모델을 반영했다. 40개 테이블 전체 구현은 아니다. 법규 버전·조문·원본 수집 쓰기 기능도 이번 범위에 포함하지 않았다.
- 공통코드는 경로 기반 읽기 API만 제공한다. 마이그레이션에 대표 코드 9개와 생성 이력을 같은 트랜잭션으로 초기화한다. 관리용 쓰기·복구 API는 제공하지 않는다.
- 초기 Next.js 화면을 한국어 AURORE 법규 검색으로 교체했다. 실제 API 응답을 표시하고 미등록·검색 결과 없음·연결 실패 상태를 구분한다. FastAPI 서비스명과 상태 확인 주소를 정리했다.

## 데이터 보존과 배포

기존 최초 마이그레이션은 변경하지 않았다. 후속 `20261105000000_aurore_foundation`은 기존 `laws`를 이름 변경하고 행·PK·시퀀스를 유지한다. 기존 시각은 Prisma의 UTC 저장 관례에 따라 UTC로 해석해 TIMESTAMPTZ로 전환한다. 실제 데이터가 다른 시각 기준을 사용했다면 적용 전에 조정해야 한다.

기존 출처는 임의로 법제처 등으로 추정하지 않고 `LEGACY`로 표시한다. 실제 법규 버전·시행일·원문을 임의 생성하지 않는다. DB·계정·Docker 볼륨 이름은 보존했다. 생성한 Prisma Client는 기존 규칙대로 Git 추적 대상이 아니다.

**기존 DB에는 접속하거나 마이그레이션을 적용하지 않았다.** 적용 전 백업·기존 스키마와 이력·시각 기준을 확인해야 하며, 애플리케이션 변경과 DB 변경을 함께 배포해야 한다. 적용 후 예전 바이너리는 변경된 테이블명과 호환되지 않는다. 자동 되돌리기나 데이터 초기화 명령을 제공하지 않는다.

## 검증

- Prisma 스키마 검증·Client 생성, NestJS 빌드, TypeScript 검사, 백엔드 코드 검사 통과.
- 단위·메모리 DB 테스트 12개, HTTP 연결 테스트 3개 통과. 메모리 DB 테스트는 PGlite를 개발 의존성으로 사용하며 실제 `DATABASE_URL`을 읽지 않는다. 테스트 데이터만 생성한다.
- 프런트엔드 코드 검사 및 Webpack 프로덕션 빌드 통과. Windows에서 기본 Turbopack의 CSS 처리 자식 프로세스가 종료되는 문제가 있어 `build` 스크립트가 지원되는 Webpack 방식을 사용하도록 정리했다.
- FastAPI 파일의 Python 구문 검사 통과. 실제 AI 서버 기동·외부 AI 연동·실제 PostgreSQL 17 배포 환경 검증은 별도다.

## 후속 범위

회원·비회원 인증, 채팅·AI 예산 실행, 사건·문서, 북마크·알림은 새로 구현하지 않았다. 탈퇴 ID 보존, 인증기간, 개인정보 유형별 보존기간 등 미결정 사항은 유지한다. 관리자 원문 열람 기능도 추가하지 않았다. 이 문서는 해당 기능들이 출시 가능한 상태라는 뜻이 아니다.
