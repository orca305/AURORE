# 공통 화면 개선 — 2026-11-17

사용자 요청에 따라 기존 상담 기록 테마를 유지하면서 조작 방식과 표시를 정리했다.

- 흰색 버튼과 동작 링크의 마우스 반응, 비활성 배경·글자·테두리, 40px 공통 조작 높이를 적용했다. 검색·페이지 선택과 관리 화면 필터도 맞췄다.
- 다크모드 사이드바는 채도가 낮은 짙은 회색으로 조정했다.
- 오른쪽 아래에 우정범 저작권 표시를 추가하고 스크롤 버튼과 간격을 뒀다.
- 새로고침은 모든 화면의 공통 오른쪽 상단에서 아이콘만 표시한다. 진행 상태와 접근성 이름을 제공하며 페이지 전체를 다시 불러온다.
- 검색 조건 초기화를 추가했다. 목록의 10/20/50개 선택은 유지하면서 검색·필터·페이지 위치를 기본값으로 되돌린다. 대화에서 사건 연결 검색은 패널 안에서 초기화한다.
- 우상향 화살표를 제거하고 해당 동작 링크에 버튼 형태를 적용했다. 법제처 원문은 기존 새 창 열기 속성을 유지한다.
- 첨부파일 버튼을 보내기 옆으로 옮기고 아이콘을 뺐다. 변환 결과를 확인하는 절차는 유지하고 화면의 Markdown 설명은 일반적인 변환 표현으로 바꿨다.
- 나의 사건으로 메뉴·제목·링크를 통일하고 사건 목록 제목의 글자 크기를 수정했다.
- 법규·판례 검색에서는 제목 옆 별표로 관심 상태를 표시한다. 등록 상태는 채워진 별이며 접근성 이름은 등록/해제를 구분한다.
- 관심 판례의 정정 알림과 고정 판본 비교를 연결했다. 세부 기준은 [알림 문서](NOTIFICATIONS.md)를 따른다.

## 검증 범위

프론트엔드 정적 검사·배포 빌드, 백엔드 빌드·43개 단위 검사, 독립 PostgreSQL DB의 관심 항목·법령 알림·판례 알림 통합 검사를 통과했다. 회원·관리자·판례 비교 화면 11곳에서 인증된 서버 렌더링 응답, 공통 새로고침·저작권, 판례 정정 비교의 변경 표시도 확인했다. 이는 서버 응답 검사이며 실제 화면 배치나 마우스 반응을 검증한 것은 아니다. 기존 백엔드 경고 10개는 남아 있다. AI 학습·추론·성능 평가는 실행하지 않았다.

이번 공통 개선 화면의 실제 브라우저 검증은 도구가 Windows 브라우저 주소를 확인하지 못해 중단됐다. 앞선 관심 법령 알림 화면 검증과 구분하며, 이번 변경의 시각 검증을 완료한 것으로 보고하지 않는다.
