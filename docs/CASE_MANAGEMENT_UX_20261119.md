# 나의 사건·첨부자료 관리 안내 개선

2026-11-19. 노트북에서 원격 연결 없이 일반 기능을 개발했다. 데스크탑 DB·원문·모델과 스키마는 변경하지 않았다.

## 사건·사실관계 입력

- 제목·분류·내용·관련 날짜를 바꾸면 확인 체크를 해제해 변경한 내용을 다시 확인하도록 한다.
- 제목 80자, 사실관계 4,000자 길이를 표시하며 공백뿐인 필수 내용과 미확인 상태는 저장 버튼을 비활성화한다. 비활성 이유도 표시한다. 사용 종료된 분류는 현재 사용할 수 있는 분류를 다시 선택한다.
- 저장할 제목·분류 또는 날짜·내용 길이를 요약한다. 삭제 확인에는 실제 사건/사실관계 제목과 영향을 받는 범위를 표시한다. 삭제는 기존 소프트 삭제 정책 그대로다.
- 실제 달력 날짜를 화면과 서버 액션 양쪽에서 확인한다. 윤년·월말·0001~9999년 범위를 검증하며 관련 날짜의 빈 값은 허용한다. 사건 관련 날짜와 법령 조회 기준일은 별개다.
- 저장 결과가 불확실하면 입력과 처리 번호를 보존하고 ‘같은 요청으로 결과 확인’으로 재시도한다. 정상 응답이어도 JSON 형식이나 사건 ID가 맞지 않으면 성공으로 처리하지 않는다. 서버의 중복 요청 영수증/버전 검사 정책은 바꾸지 않았다.
- 최신 내용 확인은 새 탭으로 열어 현재 입력을 유지한다. 사실관계 수정/대화 초안/삭제 폼은 사건 버전이 바뀌면 확인 상태를 초기화하도록 키를 지정한다.

## 첨부자료 내용 확인

- 변환 결과에서 파일명을 확인할 수 있다.
- 등록한 자료의 내용 보기에서 이름·실제 길이·이번 질문 선택 여부를 표시한다. 그 화면에서 바로 선택/해제할 수 있고 기존 3개·합계 12,000자 검사도 적용한다.
- 삭제 확인에 자료 이름과 이번 질문 선택에서 함께 제외되는지 표시한다.
- 새 모델 호출·학습·자동 공개·사용자 원본 전송은 추가하지 않았다.

## 검증과 남은 확인

프런트 빌드·정적 검사 통과. Node 검사 5개(새 사건 폼 2개 + 기존 선택 2개 + 대화 용어 검색 1개) 통과. 가짜 인증/응답 서버로 실제 Next 서버의 사건 등록·상세·사실관계 수정·타임라인 렌더링을 확인했다. 실제 날짜/길이 경계, 초기 저장 비활성, 삭제 대상 제목, 미로그인 전환·목록 조회 실패도 확인했다.

브라우저에서 직접 입력을 고치고 확인 체크가 해제되는 상호작용, 실제 저장/이력/동시 수정과 파일 변환·선택·삭제의 전체 흐름은 데스크탑 연결 후 확인할 범위다. 가짜 응답 검사를 실제 DB 저장 성공으로 기록하지 않는다. 화면 위치·색상은 사용자 확인 범위다.
