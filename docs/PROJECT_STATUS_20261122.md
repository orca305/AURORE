## 3. AI 파이프라인
1. **질문 분석**(로컬 12B): 검색어·법률용어·관련 법령 이름
2. **조문 짚기**(Claude Haiku): 질문에 적용될 법령·조문. 법령 이름을 정식 명칭으로 맞춰(별칭 표 + 유사 이름) DB에서 직접 조회
3. **검색**: 어휘 + 의미(bge-m3) + 법령 중심 벡터 + 상황 사전 + 핵심 법령 가점 + 법령별 최소 후보 보장
4. **답변**(Claude Haiku): 결론·할 일·알아 둘 내용·주의점. 근거가 확인된 항목에만 근거 조문 표시(없으면 표시 없음), 관련 판례 항목 추가
5. **검증**(코드): 원문 해시·인용 글자 일치, 원문에 없는 조문 번호·단정 표현 제거, 원문에 없는 숫자는 표시, 인용 법령 일치 검사
6. **안전망**: 비법률 질문 거절, 예산 소진·장애 시 로컬 12B로 자동 전환(쿨다운), 생성형 실패 시 예전 방식으로 대체
7. **운영**: 법령 원문 캐시(용량 기준 + 핵심 21개 상시 유지), 서버 시작 시 워밍업, 서비스 감시·자동 재시작

## 4. 품질 측정(재현 가능한 평가 도구, 합성 질문)
| 시점 | 홀드아웃 30문항 통과 | 비고 |
|---|---|---|
| 개선 시작 | 18/30 | 후보 안에서 고르는 방식, e4b |
| 선별 보정 + 12B | 24~25/30 | 오인용 5 → 1 |
| **생성형 + Haiku(현재)** | **29/30** | 오인용 1, 비법률 질문 억지 답 0, 평균 10.2초 |
- 같은 50문항에서 Haiku 48 / Sonnet 48 / 로컬 12B 43. 정확도는 Haiku=Sonnet, Haiku가 6초 빠름 → Haiku 고정.
- 측정 중 **원문 캐시가 필요한 법령을 밀어내 후보가 사라지는 버그**를 찾아 고침(민법·형법 질문에서 엉뚱한 법령이 인용되던 원인).
- 한계: 평가 정답은 법령 이름 단위, 질문은 짧은 합성 질문, 표본 30개, 법률 전문가 검토 없음.
