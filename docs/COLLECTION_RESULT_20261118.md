## 검증과 서버 상태

- 수집 도구/사전 점검 테스트 2건 통과.
- 저장된 원문 8개를 다시 로딩해 청크 13,911개를 확인했다. 원문 해시 검증과 인용 구간 검증을 통과했다. 청크 수는 DB의 조문·부칙 저장 항목 수와 다르다.
- 기존 백엔드 `/legals`가 정확히 8개 법령명을 반환하고, 각 법령 상세 조회 8건이 HTTP 200임을 확인했다.
- 프런트 `/legals` HTTP 200과 민법 이름 표시를 확인했다.
- 새 인증값을 실행 중인 백엔드에 반영하려는 재시작 명령은 실행 정책에 의해 차단됐다. 기존 서버의 DB·원문 조회는 정상이다. 수집 CLI는 새 환경 파일을 읽어 이미 실제 수집을 완료했다. 백엔드 내부에서 인증값이 필요한 관리 기능을 사용할 때는 환경 파일을 읽어 백엔드를 다시 시작해야 한다. 다른 경로로 재시작 제한을 우회하지 않았다.
- AI가 새 8개 법령에 대해 생성하는 해설 품질·정확도를 평가한 결과는 아니다.
