## 수집 구현과 재개

`backend/tools/collect-current-laws.mjs`는 기존 공식 원문 검증·스냅샷 저장·법령 적재 함수를 재사용한다. 법령별 트랜잭션과 기존 advisory lock을 유지한다. 완료 기록은 DB 커밋 후 원자적으로 생성하며 실행 잠금으로 같은 배치의 동시 실행을 막는다. 커밋 직후 기록 전에 중단되면 같은 법령을 다시 처리하되 기존 적재의 중복 검사를 거친다. 오류가 발생하면 해당 실행을 중단하고 이전 커밋을 보존한다.

원문 응답에서 조문단위가 배열 대신 단일 객체인 법령도 공통 검증 함수에서 처리한다. 법령 ID·시행일·본문 존재 검사는 유지한다.

저장소 루트에서 기존 비공개 환경 파일을 사용한다. 한 번에 최대 100개이며 아래 명령은 다음 미완료 50개를 처리한다.

```powershell
node --env-file=local-dev/.env --use-system-ca backend/tools/collect-current-laws.mjs apply D:/DATA/collection-runs/current-20261119 D:/DATA/snapshots 50
```

프로세스가 비정상 종료되어 잠금이 남으면 종료된 로컬 프로세스인지 확인한 뒤 마지막 인수에 `--recover-lock`을 붙인다. 다른 호스트나 잘못된 잠금 기록은 자동 인수하지 않는다. 완료 기록은 같은 DB를 계속 사용하는 수집 재개용이며 DB 복원·삭제·원문 손실을 탐지하는 무결성 감사는 아니다. DB를 과거로 복원했을 때 기존 완료 기록만 믿고 재개하지 않는다.

새 날짜의 현행 목록을 만들 때는 새 실행 디렉터리에 `plan <새 실행 디렉터리>`를 실행한다. 기존 목록은 덮어쓰지 않는다. 현행 목록은 계속 바뀌므로 이번 고정 목록의 최초 수집과 이후 갱신은 구분한다.

공식 API 참고: [국가법령정보 공동활용 가이드](https://open.law.go.kr/LSO/openApi/guideList.do), [시행일 기준 본문 조회](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=lsEfYdInfoGuide).
