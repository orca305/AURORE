# 학습 활용 동의·철회 — 2026-11-17

마이페이지에서 서비스 이용과 분리된 선택 동의를 변경하고 10/20/50개씩 이력을 조회한다. 가입은 기본 미동의이며 학습 활용에 동의하지 않아도 일반 기능을 사용한다. 현재 사용자 자료를 학습하는 기능은 연결하지 않았으며 동의 저장으로 학습·추론·유료 API를 실행하지 않는다.

## 저장과 경쟁 요청

기존 AURORE / USER_AGR / LEARNING 공통코드와 user_agr_yn_hist를 사용한다. 새 테이블이나 마이그레이션은 없다. 정책 버전 3.3과 초 단위 시각으로 변경을 추가하고 과거 행은 덮어쓰지 않는다. 가입 시에도 시각을 초 단위로 명시해 DB의 반올림으로 미래 시각이 생기는 문제를 피한다.

회원·세션 재확인과 회원 행 잠금 후 화면이 받은 최신 이력 번호를 비교한다. 다른 창에서 변경했으면 409로 거부하며 최신 선택을 확인하도록 안내한다. 같은 선택·같은 정책의 반복 저장은 이력을 늘리지 않는다. 미래 시각의 이력은 현재 선택·공개 이력에서 제외하고, 미래 이력이 존재하는 동안 새 변경을 거부해 뒤늦게 선택이 뒤집히지 않도록 한다. 공통코드가 비활성·잘못된 상태이면 저장과 조회를 실패 처리한다.

## API

- GET /auth/learning-consent: limit=10|20|50, offset=0..100000. 현재 선택, 최신 이력 번호, 정책 버전, 이력·건수·다음 페이지를 반환한다.
- POST /auth/learning-consent: agreed(boolean), revision(화면에서 받은 이력 번호), confirmed=true. 동의 또는 미동의·철회를 기록한다.
- 모든 응답은 no-store다. 회원 ID를 받지 않으며 인증·검증을 통과한 본인의 이력만 반환한다. 추가 회원 ID·잘못된 개수·임의 상태·과거 화면의 갱신을 거부한다.
- Next.js 변경 액션은 동일 출처와 현재 서버 세션을 확인한다. 성공을 확인하지 못하면 저장 완료로 안내하지 않는다.

## 연결된 것과 남은 것

관리자 개인정보 집계는 같은 공통코드와 시각·이력 번호 기준으로 최근 선택을 반영한다. 탈퇴는 미동의 이력을 추가하고 이후 설정 변경을 차단한다.

이번 기능은 동의 선택과 이력 관리다. 실제 사용자 자료 선별, 개인정보·민감정보 정제와 품질 승인, 학습 사본 7일 관리, 학습 작업과 동의 버전 연결, 진행 중 학습 취소, 이미 학습한 모델의 영향 제거, 캐시·임베딩·백업의 파기·철회 전파가 완료된 것은 아니다. 이 경계를 마이페이지에도 표시한다. 사용자 동의를 즉시 학습 실행으로 해석하지 않는다.

## 검증

독립 임시 PostgreSQL DB의 합성 회원으로 기본 미동의, 동의·철회와 과거 이력 보존, 같은 선택 반복, 동시 저장의 한 요청 거부, 오래된 화면의 덮어쓰기 차단, 잘못된 요청·타인 ID 거부, 실패 되돌림, 미래 이력 제외, 비활성 코드 거부, 10개 페이징, 탈퇴 후 접근 차단을 확인했다. 기존 인증·탈퇴·관리자·관심 항목·알림·보관 점검도 회귀 검사했다. 실제 회원의 선택은 변경하지 않았다.
