# AURORE 요구사항 대비 진행도 재점검

기준: 2026-11-16 마감 커밋 `6815346`, 점검 정리일 2026-11-17.

별도 RFP 원본은 현재 접근 가능한 작업 폴더에서 찾지 못했다. 따라서 확정된 v3.3 최종설계와 2026-11-06 WBS의 완료 기준을 요구사항 기준으로 사용했다. 이후 사용자 변경(브라우저 종료 시 로그인 만료, 목록 10/20/50 선택 등)이 과거 설계보다 우선한다. 이 문서는 코드·DB 변경이나 실제 AI 성능 평가 결과가 아니다.

## 결론

전체 약 **45~50%**, 중심 추정 **46%**. 앞선 65%는 AI 연결 기반과 실제 사용 품질을 혼동하고 학습·부가 기능의 미구현 범위를 과소 반영했다. 이어 말한 51~54%도 AI 비중만 임의 조정한 추정이어서 이번 항목별 대조로 대체한다.

아래 점수는 사람이 매긴 요구사항 충족도다. 시험 통과율·실제 투입시간·남은 일정·법률 정확도가 아니다. 코드 존재와 합성 테스트를 실제 모델 성능이나 베타 출시 완료로 환산하지 않는다.

## 산정 기준

- 0%: 요구사항의 실행 가능한 구현·검증 근거를 확인하지 못함.
- 25%: 코드·실험·부분 연결 기반이 있으나 완료 기준의 실제 실행 근거 부족.
- 50%: 일부 동작이 확인되지만 요구사항의 주요 경로가 남음.
- 75%: 핵심 경로가 구현·검증됐으나 통합·실제 장비·품질 확인이 남음.
- 100%: 해당 WBS 항목의 구체 완료 기준을 충족한 근거가 있음. 서비스 전체 출시 승인과 다름.

원래 WBS 예상시간으로 가중한다. 기능 작업 110시간 중 인정 점수 환산 50.75시간 = 46.1%. 수정 여유·사용자 공개 판단 14시간은 별도 관리하며 분모에서 제외한다. 이 환산치는 실제 완료한 노동시간이 아니다. WBS 자체의 시간 배분도 추정이므로 최종 표시는 45~50% 범위로 한다.

## 확인한 핵심 사실

- `ai-server/intent_lab/questions.tsv`: train 84, validation 24, test 36, 총 144개. 단일 메시지 합성 자료다.
- `ai-server/intent_lab/intent.py`: CPU 학습·저장·독립 분할·임계값 선택 코드가 있다.
- `backend/tools/demo-conversation-intent.mjs`: 현재 일반 대화 분기는 정규식 규칙이다. ML 성능으로 보고하지 않는다.
- `backend/src/chat/answer.service.ts`: 일반 검색은 저장 원문 후보 조회 후 `/documents/answer`를 재사용한다. 모델이 준비되지 않으면 후보 안내를 반환한다. 문서와 일반 검색의 설명 문구는 고정 안내가 중심이다.
- `ai-server/document_answer.py`: 실제 Ollama 호출 코드는 있지만 주 기능은 관련 원문 구간 선택이다. 같은 모델의 추가 검토 호출을 독립 법률 검증으로 인정하지 않는다.
- `backend/.eval-results`의 확인한 보고서: offline PASS와 local NOT_RUN. 실제 모델 평가 PASS 결과를 확인하지 못했다. 과거 보고서는 당시 Git·소스 해시를 따르며 현재 커밋 전체의 합격증으로 사용하지 않는다.
- 검색은 어휘 기반이다. 임베딩·벡터 검색·학습 재정렬은 확인하지 못했다.
- 개인정보 점검은 조회 전용이다. 소프트 삭제 뒤 원문 파기 완료를 뜻하지 않는다.
- Prisma 모델·화면·테스트 수는 요구사항 완료율로 사용하지 않는다.

## 개발 순서 조정

1. CPU 의도 분류기의 실제 학습·평가·API 연결. 목표 미달은 그대로 기록하고 근거 없이 일반 대화로 분류해 법률 검색을 생략하지 않는다.
2. 데스크탑에서 로컬 모델 설치·법률 RAG 연결. 인용 선택과 쉬운 법률 해설 생성을 구분한다.
3. 미사용 질문 세트로 검색·답변·보류·법률 관련성·지연 평가. 통과 전 베타 AI 완료로 표시하지 않는다.
4. 실제 공개 전 개인정보 파기·철회·로그·복구·배포를 완료한다. 이 항목은 공개 필수 조건이다.
5. 용어·관심 항목·학습 재정렬은 WBS에 남겨 두고 단계별 출시 범위를 명시한다.

이 평가는 AI 영역을 통째로 10~20%로 단정하는 것도 대체한다. ML은 코드 기반 단계, RAG는 부분 연결 단계, 실제 법률 품질 평가는 미실행이다. 서로 다른 상태를 하나의 성능 수치로 합치지 않는다.

## 후속 일반 기능 — 회원 탈퇴

본인 비밀번호 확인·탈퇴·모든 세션 철회·미완료 작업 취소·하위 자료 소프트 삭제·실패 재시도를 추가했다. 관리자 파기 검토 계획은 조회 전용이며 실제 본문·이력·학습·백업 파기는 여전히 남았다. 위 점수는 당시 기준으로 보존하며 이번 기능만으로 진행률이나 운영 준비 완료를 다시 판정하지 않는다. [구현 범위](ACCOUNT_WITHDRAWAL.md)를 참고한다.
