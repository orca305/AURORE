## 변경한 동작

- 띄어 쓴 조문 번호와 4자리 연도의 사건번호를 별도 조건으로 인식합니다. 날짜를 사건번호로 취급하지 않도록 ‘년·월·일’ 형태를 제외합니다.
- 특정 조문을 요청하면 해당 조문으로 좁히고, 사건번호를 요청하면 해당 판례로 좁힙니다. 없는 번호를 다른 원문으로 대신하지 않습니다.
- 조문과 함께 법령명을 명시한 경우 저장된 전체 법령명이 질문과 일치하는지 확인합니다. 다른 법령의 같은 조 번호를 대신 반환하지 않습니다. 법령명의 모든 약칭·오탈자 교정은 지원하지 않습니다.
- 제목·사건번호의 검색어 일치를 본문보다 우선하고, 사용자 표현과 조사 제거 결과를 함께 보존합니다. 기존 ‘집주인→임대인’, ‘세입자→임차인’, ‘전세금→보증금’ 치환도 유지합니다.
- 긴 원문에서는 여러 검색어가 함께 들어 있는 1,200자 이내 구간을 고릅니다. 구간은 원문을 그대로 잘라 사용합니다.
- 사용자가 선택한 사건 사실관계는 검색어 보완에 사용하며, 그 안의 조문 번호가 질문에서 지정한 조문을 덮어쓰지 않도록 질문과 구분합니다.

검색은 제한된 후보를 조회하는 어휘 기반 방식이며 임베딩 기반 의미 검색은 아닙니다. 서로 다른 개념을 같은 단어로 표현하는 경우까지 자동 해결하지 않습니다. 검색어는 최대 16개, SQL 후보는 12개, AI 전달 원문은 최대 3개이며 긴 본문에서는 검색어마다 최대 128개 위치를 검사합니다. 자료가 커지면 실제 검색 시간과 누락률을 측정해 인덱스·후보 확대·의미 검색을 검토해야 합니다.

정정 원문·소프트 삭제·시행일·원문 해시 확인은 유지했습니다. 일부 사례의 개선을 전체 법률 검색 재현율이나 법률 정확도 수치로 환산하지 않습니다.
