# 회원 보안·학습 동의 처리 안내 개선

2026-11-19. 노트북에서 실제 사용자 설정 변경·모델 실행 없이 개발했다. DB 스키마, 사용자 동의 값, 학습 정책과 실제 학습 기능은 변경하지 않았다.

## 학습 활용 동의·철회

- 현재 선택과 이번에 저장할 선택을 구분한다. 동의와 미동의/철회의 버튼·결과 문구를 구체화한다.
- 저장 성공 응답의 선택·이력 번호·변경 여부를 검사하고 현재 선택/최근 이력 화면으로 이동한다. 조회 결과와 일치하는 경우에 완료 안내를 표시한다. 성공 여부를 모르면 완료로 표시하지 않는다.
- 충돌·불확실한 결과는 선택을 잠그고 현재 상태 재조회로 안내한다. 새 조회/확인 없이 과거 버전으로 반복 저장하지 않는다. 인증 만료는 로그인 안내로 구분한다. 기존 서버의 이력 버전 비교·행 잠금은 유지한다.
- 조회 응답의 선택·이력·날짜·페이지 형태를 확인한다. 잘못된 응답을 기본 미동의로 대신 표시하지 않는다. 현재 상태를 읽지 못하면 변경 폼도 표시하지 않는다.
- 적용 정책 버전과 새로고침을 표시한다. 이력 자체가 없는 경우와 조회 범위를 넘어 빈 페이지인 경우를 구분하고 최근 이력 링크를 제공한다.
- 선택 동의, 서비스 이용과 분리, 현재 사용자 자료 학습 미연결, 철회가 기존 모델 영향 제거 완료를 뜻하지 않는 안내를 유지한다.

## 회원 보안

- 비밀번호 변경에 정규화 후 8~16자, 현재와 다른 값, 확인 일치 검사를 화면/서버 액션에 적용한다. 서버의 추측하기 쉬운 비밀번호 거부·현재 비밀번호 확인·세션 종료 정책은 유지한다.
- 길이는 기존 서버와 같은 NFC + Unicode 코드 포인트 기준이다. 이모지·조합형 문자의 원시 UTF-16 길이로 임의 제한하지 않는다. 브라우저 상태에는 길이/안내만 보관하고 비밀번호 문자열을 별도 React 상태나 로그에 보관하지 않는다.
- 모든 기기 로그아웃에 확인란을 추가하고 서버 액션도 확인 여부를 검사한다. 단일 기기 로그아웃 동작은 유지한다.
- 회원 액션의 빈 본문·null·배열·잘못된 JSON을 안전하게 처리해 안내가 끊기지 않도록 한다. 응답 원문·인증정보를 오류 안내에 복사하지 않는다.

## 검증

프런트 빌드·정적 검사 통과. 새 Node 검사 5개(비밀번호/Unicode, 동의 변경 결과, 비정상 JSON, 동의 조회 형태, 실제 Next 서버의 마이페이지 렌더링) 통과. 마지막 검사는 임시 인증/응답 서버의 GET만 사용해 완료 안내의 현재 선택 일치, 전체 로그아웃 초기 비활성, 빈 이력 페이지, 잘못된 동의 응답 시 폼 미표시를 확인했다.

실제 비밀번호 변경·로그아웃·동의 POST·철회·이력 저장은 실행하지 않았다. 실제 로그인과 저장/충돌·브라우저 입력 상호작용은 데스크탑 연결 후 확인한다. 가짜 응답 검사 결과를 실제 개인정보 처리 완료로 기록하지 않는다.
