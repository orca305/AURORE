# AI 작업 처리 결과와 운영 진단

2026-11-16에 추가한 관리자 기능입니다. 작업의 실행 상태와 답변 근거의 확보 여부를 구분합니다. 관리자 원문 열람은 계속 비활성화되어 있으며, 대화·사건·첨부 본문이나 사용자 식별값을 진단 응답에 추가하지 않았습니다.

## 어디서 확인하나

- 운영 현황의 최근 작업: 상태·처리 방식·처리 결과·오류 유형
- AI 작업 목록: 결과별 필터, 날짜·오류·상태 조건, 10/20/50개 조회
- 작업 상세: 결과 설명, 점검할 사항, 오류 유형, 시도·기한·작업 점유 시간

화면은 전체 상태를 기본으로 보여 줍니다. 기존 API의 기본 상태 필터는 FAILED를 유지하며 화면이 명시적으로 status=all을 전달합니다. 집계는 화면의 현재 검색 조건에 따른 값입니다.

## 실행 상태와 결과는 별개

`SUCCEEDED`는 응답 저장이 끝났다는 뜻입니다. 원문 후보만 제공했거나 보완 질문을 저장한 경우에도 이 상태일 수 있으므로, 반드시 처리 결과를 함께 확인합니다.

| 결과 코드 | 표시 | 의미 |
| --- | --- | --- |
| EVIDENCE_FOUND | 인용 근거 확인 | 원문 근거를 확보함. 개별 사건의 법률 적용 확정을 뜻하지 않음 |
| SOURCE_GAP | 저장 근거 없음 | 검색 조건·판본·공개 상태·원문 검증을 통과한 연결 가능한 후보가 없음 |
| RELEVANCE_GAP | 관련 근거 미확인 | 후보가 있었지만 질문 관련성 검토를 통과한 인용이 없음 |
| DOCUMENT_GAP | 첨부 근거 미확인 | 선택한 첨부자료에서 질문에 대한 인용을 확보하지 못함 |
| AI_NOT_READY | AI 미준비 · 원문 후보 | 준비 상태를 확인하지 못해 관련성 검토 없이 원문 후보만 제공함 |
| FACTS_UNCONFIRMED | 사실관계 확인 필요 | 확인 질문을 하거나 미확인 사실의 추정을 보류함 |
| SOURCE_CHANGED | 원문 변경 · 답변 보류 | 원문 대조 실패 또는 저장 전 원문 상태 변경으로 보류함 |
| GUIDANCE | 일반 안내 | 법률 근거를 인용하지 않는 안내 응답 |
| null | 결과 분류 없음 | 진행 중이거나 결과 분류 도입 이전의 작업. 본문으로 결과를 추정하지 않음 |

기존 작업의 결과를 소급 입력하지 않았습니다. 이 값은 답변 저장과 같은 트랜잭션에서 기록하며, 결과는 허용된 코드만 저장하는 CHECK 제약을 적용했습니다. 원문이 저장 전에 바뀌어 인용을 제거한 경우에는 SOURCE_CHANGED로 기록합니다.

## 오류 분류

- AI_UNAVAILABLE: 로컬 AI 연결·응답을 확인하지 못함
- AI_UPSTREAM_FAILURE: AI 서버가 502로 종료한 모델 연결·출력 처리 실패. 원문 불일치라고 단정하지 않음
- AI_CONFIGURATION: 허용된 로컬 주소 설정 확인 필요
- EVIDENCE_INVALID: 응답 형식·원문 일치·출처·중복·검토 표시 검증 실패
- SOURCE_UNAVAILABLE: 선택한 자료를 사용할 수 없거나 허용 범위를 벗어남
- CASE_CONTEXT_CHANGED: 사건이나 사실관계가 바뀌어 답변 저장 취소
- GENERATION_FAILED / TOTAL_TIMEOUT / ATTEMPTS_EXHAUSTED: 그 밖의 실행 실패·기한·시도 한도

예외 메시지·SQL 오류 원문·모델의 출력 본문을 관리자 API로 전달하지 않습니다. 알 수 없는 코드는 OTHER로 축약합니다. 오류는 현재 작업에 남은 코드이며 모든 과거 시도별 오류를 누적한 이력은 아닙니다. 재시도 후 성공하면 오류 코드가 비워질 수 있습니다.

첨부자료 질문은 AI 준비 확인 단계에서 거부되면 작업 자체가 생성되지 않습니다. 이 요청은 AI 작업 집계에 포함되지 않습니다. SOURCE_GAP만으로 자료 미수집·검색 표현 불일치·판본 필터·원문 검증 제외 중 정확히 어느 단계 때문인지 확정하지 않습니다.
